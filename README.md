# MusX Space 2.0

Первая рабочая версия сканера внутрибиржевых треугольников Binance Spot. Циклы начинаются и заканчиваются в USDT. Приложение принимает сумму, минимальную доходность и необязательную комиссию на каждый шаг. Пустая комиссия включает валовой расчёт. При заполненном поле итог и процент учитывают указанную комиссию. Все операции рассчитываются по публичным снимкам стаканов с учётом доступного объёма, шага количества и требований к номиналу. Результат является оценкой для ручного исполнения.

## Запуск

На Windows установите Python 3.12 x64 с компонентом Tcl/Tk. В корне проекта выполните:

```powershell
python app.py
python -m unittest discover -s tests -v
```

Нажмите **Scan Now**. При высоком пороге таблица может оставаться пустой. Строка над таблицей показывает число рассчитанных и проверенных маршрутов. Таймер показывает время непрерывного наблюдения маршрута между успешными проверками и сбрасывается при потере данных, остановке или изменении параметров.

## GitHub и Windows

Распакуйте ZIP и загрузите содержимое каталога MusX-Space-2, включая скрытый каталог .github, в корень нового репозитория. Workflow **Windows build** запускается при push. После успешной сборки в разделе Actions будет архив MusX-Space-Windows-x64 с EXE, установщиком и SHA-256. Для локальной сборки установите Inno Setup 6 и выполните `./build.ps1` из PowerShell.

## Проверки и границы реализации

- Семь модульных тестов прошли на Python 3.12. Проверены глубина, округление, минимальный номинал, комиссия в активе получения, недостаток ликвидности, устаревшие данные и контрольный итог 1007 USDT.
- Отдельная живая проверка REST получила 10 рынков и стаканы Binance Spot. При 100 USDT движок рассчитал 12 маршрутов. Проверка подтверждает доступность данных и расчёт, величина ожидаемой прибыли зависит от снимков.
- Windows-установщик, GitHub Actions и визуальный запуск интерфейса в этой среде не проверены.
- Реализован ограниченный список пар BTC, ETH, BNB, SOL и USDT. Стаканы обновляются через REST. Снимки не атомарны и не гарантируют исполнение. Размеры округляются консервативно, остатки промежуточных активов исключены из итогового USDT. Введённая комиссия моделируется в получаемом активе. Браузерные ссылки, персональные комиссии, межбиржевые переводы, WebSocket, сверка с полным макетом, локализация UA/EN, мобильный клиент, история, избранное, аналитика и уведомления остаются вне этой версии.
- Binance Spot использует публичные [exchangeInfo и depth](https://github.com/binance/binance-spot-api-docs/blob/master/faqs/market_data_only.md). Приложение не принимает ключи API, не отправляет ордера и не инициирует вывод.
- Остальные биржи пока не реализованы и не проверены: MEXC, Bybit, Bitget, BingX, OKX, Gate.io, KuCoin, HTX, Kraken, Coinbase, BitMart, LBank, CoinEx, XT.COM, Bitfinex, Crypto.com, WhiteBIT, Phemex, Bitrue.
- Дополнительные площадки пока не реализованы и не проверены: BestChange, ChangeNOW, XNode/Exnode, Bitcheck/Bitochek и Kassa. Названия со слэшем отражают расхождение в ТЗ. Матрица возможностей всех 25 площадок ещё не подтверждена.
